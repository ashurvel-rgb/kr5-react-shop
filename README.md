# Контрольная работа №5 — React SPA Urban Set

Одностраничный интернет-магазин на React + Vite. Предметная область продолжает КР №4.

## Запуск

```bash
pnpm install
pnpm dev
```

Сборка: `pnpm build`.

## Маршруты

- `/` — главная;
- `/catalog` — каталог с поиском, категориями и сортировкой;
- `/catalog/:productId` — детальная страница, включая сценарии `/catalog/1` и `/catalog/999`;
- `/cart` — корзина, количество, итог и промокод `STUDENT10`;
- `/order` — контролируемая форма заказа;
- `*` — собственная страница 404 (например `/unknown-page`).

## Архитектура

- `src/api/productsApi.js` — API-слой с `getProducts()` и `getProductById()`.
- `src/components` — Header, карточка, список, элементы каталога и формы.
- `src/pages` — отдельные компоненты страниц.
- `src/utils` — фильтрация, форматирование и валидация.
- `public/products.json` — mock API с десятью товарами.

## Реализовано

- функциональные компоненты, JSX, props, `useState`, `useEffect`, `useMemo`;
- React Router и работающие прямые ссылки GitHub Pages через `404.html`;
- загрузка данных, loader/skeleton, error/retry и пустые состояния;
- поиск, фильтр, сортировка, карточка товара и обработка неверного id;
- полноценная корзина с `reduce`, промокодом и `localStorage`;
- избранное, светлая/тёмная тема;
- контролируемая форма с валидацией, имитацией отправки и сохранением черновика;
- адаптивная вёрстка.
